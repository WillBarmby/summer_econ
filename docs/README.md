# Historical Documentation Map

> **Historical documentation.** These files describe the former E&P/NK
> experiment interface and are retained for provenance. They are not a map of
> every active file in the current packaging branch.

The active code is documented by the repository `README.md` and the READMEs in
`src/model/` and `src/learning/`. The files below preserve the earlier model
derivations, experiment designs, artifact schema, calibration notes, results,
and replication lineage for later migration:

- `EXPERIMENT_DESIGN.md` - former controlled experiments;
- `RESULTS_AND_QUESTIONS.md` - former paper-facing results;
- `ARTIFACT_SCHEMA.md` - former reporting contract;
- `PARAMETER_PROVENANCE.md` - former experiment calibrations;
- `MODEL_DEVELOPMENT.md` - historical NK model development;
- `REPLICATION_LINEAGE.md` - verification history and archived implementation;
- `model*.tex` and `model.tex` - model derivations;
- `nk_monetary_policy_rule_notes.md` - model background.

New active design decisions should be recorded separately from these historical
documents and should describe the canonical model, learning, experiment, and
artifact contracts directly.
