# Zero-Growth E&P Sub-Artifact

This is the `gamma_bar=1` arm of the deterministic-growth sensitivity. It uses
the same standardized innovations as the original-growth arm and asks whether
positive deterministic trend growth drives the E&P results. Both specifications
complete 100 of 100 draws. The parent folder reports the paired differences.
Its standalone scalar summary is `ep_zero_growth_summary.csv`.
