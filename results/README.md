# Generated Results

Public runners save one experiment artifact and its PDF/PNG figures beneath
this directory. Generated contents are local unless explicitly designated as a
canonical research artifact.

`ep_ih_initialization_robustness/` is produced by the targeted IH runner. Its
MAT file contains all draw-level paths and diagnostics; separate IRF and
diagnostic PDF/PNG figures show conditional response summaries and all path
outcomes.

`initialization_robustness/` contains the canonical cross-model moderate-prior
comparison: one common MAT artifact and CSV summary, treatment IRFs, direct
paired differences, and a dimensionless robustness summary. The model-specific
initialization folders retain training-horizon and zero-coefficient stress tests.
